# Configuration et prise en main de l'environnement de développement

## Objectif

- Démarrer sur de bonnes bases
- Vous rendre à l'aise avec votre environnement de développement.

## Consignes

**Installation de VS Code**

- Téléchargez Visual Studio Code à l'adresse [https://code.visualstudio.com/](https://code.visualstudio.com/){:target="_blank"} et installez le.
- Installez les extensions suivantes : 
    - French Language Pack for Visual Studio (Microsoft)
    - Live Server (Ritwick Dey)
    - W3C Web Validator (Celian Riboulet)
- Désactivez la suggestion "inline" de Copilot

**Créer votre structure de répertoire**

- Créez un repertoire cegep à cet endroit C:\Users\nom
- Dans ce nouveau repertoire creez aussi un repertoire designweb
- Épinglez le repertoire design web à l’accès rapide de l'explorateur de fichier Windows

C’est dans ce repertoire que vous allez créer vos merveilles

**Créer un nouveau projet**

- Créer un nouveau projet intitulé `00_ide`
- Ouvrez ce projet dans VS Code
- Créez un fichier index.html dans votre projet.
- Inscrivez le texte `Ma première page Web` dans ce fichier.
- Lancez Live Server pour voir le résultat. 

**Création de votre compte Github**

Sur le site [http://github.com](http://github.com){target=_blank}:

- Créez-vous un compte avec votre courriel du cégep da@etudiant.cegepvicto.ca. 
- Très important le nom d’usager doit être **cgpvicto_da** (ex cgpvicto_2531123)
- Une fois connecté à Github, cliquez sur votre avatar en haut à droite et sélectionnez **Settings**
- Ensuite dans la section **Billing et licensing** sélectionnez **Education benefits** et cliquez sur **Start an application**

!!! note

    Même si vous avez déjà un compte Github vous devez en créer un autre avec les informations requises plus haut.
