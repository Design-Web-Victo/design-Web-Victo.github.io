# Organisation des fichiers

Tout au long de la session vous allez créer plusieurs projets différents et c’est important d’adopter dès maintenant une bonne structure dans l’organisation de vos fichiers. Vous pourrez réutiliser cette structure dans vos différents cours.

- [x] À la racine de votre dossier usager de windows (c:\users\nomUsager) créez le répertoire **cegep**
- [x] Dans le répertoire Cegep créez un sous-répertoire **designweb**
- [x] Pour chaque projets ou exercices, vous allez créer un nouveau répertoire, mais toujours à l’intérieur du répertoire **designweb**. Plus de détail à la page [gestion des projets](creation.md)
- [x] C'est facultatif mais vous pourriez aussi synchroniser le répertoire designweb à votre Onedrive.
