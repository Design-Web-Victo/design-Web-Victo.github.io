# Github Classroom

Github Classroom est un site qui permet aux enseignants de proposer des travaux (assignments) sous forme de dépôt Github. L'élève accède au travail depuis un lien url et un dépôt est automatiquement créé dans son compte Github. L'enseignant y a aussi accès pour lui permettre d'évaluer le travail.

Première étape, on accède à Github Classroom depuis un lien url et on se connecte à notre compte Github si ce n'est pas déjà fait

![image 1](../../assets/images/git_classroom_01.png){.center .shadow}

La première fois que vous allez accéder à la "classe", vous devez associer votre compte Github à votre nom 

![image 2](../../assets/images/git_classroom_02.png){.center .shadow}

Ensuite vous devez accepter le travail en cliquant sur "Accept this assignment"

![image 3](../../assets/images/git_classroom_03.png){.center .shadow}

Maintenant le dépôt va se créer. Après quelques secondes cliquez sur le bouton rafraichir de votre navigateur.

![image 4](../../assets/images/git_classroom_04.png){.center .shadow}

Votre dépôt est maintenant prêt. Vous pouvez cliquer sur le lien pour y accéder.

![image 5](../../assets/images/git_classroom_05.png){.center .shadow}

Il ne vous reste qu'à cloner le dépôt et commencer votre travail.

![image 6](../../assets/images/git_classroom_06.png){.center .shadow}

!!! Rappel

    Pour cloner un dépôt: 
        
    - Ouvrez l'explorateur de fichier et diriger vous à l'endroit où vous voulez créer le projet
    - Faites un clique droit dans la fenêtre de l'explorateur et sélectionner "Open Git Bash here".
    - Un terminal va s'ouvrir dans le même répertoire.
    - Entrez ensuite la commande `git clone` suivi de l'url du dépot. (Voir l'image plus haut) Vous pouvez copier-coller l'url
    - Un dossier va être créé au nom du dépôt.
    - Ouvrez ensuite ce dossier avec VS Code.

```bash title="Exemple"
git clone https://github.com/DesignWeb-A2023-gr1/dw-ex03-MathFrechette
```

## Remise de votre travail

Une fois votre travail terminé, n'oubliez pas d'utiliser les [commandes principales](./git_basics.md#resume-des-commandes-principales) pour publier votre code dans le dépôt associé à votre nom. Vous pouvez ensuite confirmer que votre projet a été mis en jour sur GitHub Classroom en retournant sur le lien de votre dépôt. En cas de doutes, n'hésitez pas à demander une confirmation de remise à votre enseignante ou votre enseignante et ce, **avant** la date/heure de remise de l'évaluation ou du projet.
