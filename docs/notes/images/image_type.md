# Les types d'images pour le web

Les images sont une partie intégrante d'un site web. Que se soit sous forme d'icone, d'image d'arrière-plan ou de photo, elles permettent d'ajouter du style et de l'attractivité à votre page.

## Type d'images

| Format         | Transparence           | Compression                                    | Idéal pour…                                  | 
| -------------- | ---------------------- | ---------------------------------------------- | -------------------------------------------- | 
| **JPEG / JPG** | Non                    | Avec perte (qualité réglable)                  | Photos, visuels riches en couleurs           | 
| **PNG**        | Oui                    | Sans perte                                     | Logos, icônes, éléments d’interface, schémas | 
| **GIF**        | Oui                    | Sans perte (256 couleurs max)                  | Petites animations simples                   | 
| **WebP**       | Oui                    | Avec ou sans perte (excellente compression)    | Photos, illustrations, animations légères    | 
| **SVG**        | Oui                    | Vectoriel (très léger pour des formes simples) | Logos, icônes, illustrations vectorielles    |
| **ICO**        | Oui                    | Variable (bitmap)                              | Favicons (icône du site)                     | 


???+ Note "Le format WebP"

      WebP est un format d'image moderne qui offre une compression avec et sans perte supérieure pour les images sur le Web. Les images WebP sont en moyenne 26% plus petite que les images PNG et entre 25 à 34% plus petites en taille que les images JPEG ([Source](https://developers.google.com/speed/webp?hl=fr){target=_blank}).

      Pour en savoir plus : [https://www.hostinger.com/fr/tutoriels/webp](https://www.hostinger.com/fr/tutoriels/webp){target=_blank}
